# Abhishek's Portfolio

A responsive student portfolio built with plain HTML, CSS and JavaScript. It features an interactive light control, theme colors, animated sections, and a scripted chatbot preview.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

This repository is prepared to deploy from the `main` branch with GitHub Actions. The intended site address is:

`https://codewithabhi004.github.io`

The chatbot and contact form are frontend demos; they do not connect to an AI service or send/store messages.
